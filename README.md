# Monday, Reviewed in One Line

Entry for the make.fun bounty
[u-zeroxfive-monday-reviewed-in-one-line-e55de3c1](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1).

`main.ts` writes a single one-line review of my Monday (123 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Nothing else is written. The program is
deterministic, uses no network, and runs in well under a second.

Run: `MAKEFUN_OUTPUT_DIR=out node main.ts`
